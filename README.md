# TubeScout

Free YouTube topic and SEO research tool. One static page, no server.

- Trends: YouTube search suggestions, YouTube popular chart, Wikipedia top pages, Reddit
- Supply check: how many videos cover a topic, with Demand / Competition / Opportunity scores
- SEO titles, description, tags and hashtags

Open the site, go to Settings, and add your own free YouTube Data API key. Keys are stored only in your browser.
