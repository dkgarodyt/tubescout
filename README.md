# TubeScout

A personal YouTube assistant that runs free in the browser. One static page, no server.

- **Home**: one-tap "Find my next video", current video progress, saved ideas, history
- **Discover**: topic supply check (Demand / Competition / Opportunity scores), ideas from YouTube search, YouTube popular chart, Wikipedia top pages, Reddit
- **Create**: titles, description, tags, hashtags, hooks, outline, thumbnail text, upload checklist
- **Channel**: your recent video performance, AI audit, competitor tracker
- **Assistant**: AI chat that knows your channel, current video and saved ideas

Open the site, tap the gear icon and add your own keys (YouTube Data API key; Claude API key for the AI features). Keys are stored only in your browser.
