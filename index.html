How to get the keys

YouTube API key (free, 5 min)

  1. Open console.cloud.google.com and create a project.
  2. Search for YouTube Data API v3 and tap Enable.
  3. Go to APIs & Services → Credentials → Create credentials → API key.
  4. Edit the key: set API restrictions to YouTube Data API v3, and under Website restrictions add dkgarodyt.github.io/*.
  5. Paste the key above. You get 10,000 units a day; it resets at 1:30 PM IST.

How the scores work

Demand = trend strength + how often YouTube suggests the phrase + average views of the top 20 videos + view speed of videos from the last 30 days.
Competition = total results + share uploaded in the last 90 days + median subscribers of the ranking channels + how many titles use the exact keyword − small channels (under 10k subs) in the top 20.
Opportunity = √(Demand × (100 − Competition)) + bonuses for outliers (views at least 3× subs) and old results. 60+ is a strong topic.
All numbers are estimates from free data, not exact search volumes.
